热销表盘的四层逻辑

四层必须同时成立，才容易从吸引变成留存

1. 主题识别

用 IP、角色、情绪或相册形成第一眼识别，让用户立刻知道“它是什么”。

关键：主体清晰，风格统一，1 秒内可识别。

2. 状态回应

亮屏、充电、点击或数据变化时，角色、表情、颜色或装饰发生反馈。

关键：动态有触发逻辑，不是无意义播放。

3. 个性化

照片、时间样式、颜色和组件可切换，让用户把同一主题变成自己的版本。

关键：至少有 2—3 个可感知编辑入口。

4. 日常可用

时间始终清晰，电量、天气、步数、心率、睡眠等信息真正帮助用户快速查看。

关键：功能服务于日常，不让装饰和动效破坏阅读。

交互和组件规范

用来指导单个表盘的功能取舍

信息优先级

  1. 一级：时间，保证 1 秒可读。
  2. 二级：日期、星期、电量。
  3. 三级：天气、步数、心率、卡路里、睡眠。
  4. 四级：装饰、角色动作、氛围动画。

组件数量建议

  1. 极简型：时间 + 3 个数据。
  2. IP 型：时间 + 4—5 个数据。
  3. 万能型：时间 + 6—8 个数据。
  4. 功能跳转放在对应数据区域。

动态状态建议

  1. 默认状态：1—2 组。
  2. 亮屏动画：3—5 组。
  3. 数据状态：3—9 组。
  4. 充电状态：单独 1 组。

触发方式建议

  1. 自动：亮屏、时间、步数、电量、压力。
  2. 点击：切换角色或动态。
  3. 长按：切换样式、照片和组件。
  4. 避免持续高频动画影响阅读。

最低可用自定义

  1. 2—3 种时间样式。
  2. 2 套深浅组件颜色。
  3. 3 张以上背景或角色画面。
  4. 3—5 个数据模块可替换。

高价值自定义

  1. 支持背景裁切和多图切换。
  2. 时间位置可选，避免压住主体。
  3. 功能图标可编辑或关闭。
  4. 保留默认开箱即用方案。
